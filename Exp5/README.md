# experiments (stats1-5)

This workspace contains five experiment folders (`exp1` through `exp5`). Each folder contains a Python script (and for `exp1`-`exp4` a `diabetes.csv` dataset) implementing small data science experiments.

How to run an experiment:

1. Create a Python virtual environment and install common dependencies:

```
python -m venv .venv
.\.venv\Scripts\activate
pip install --upgrade pip
pip install pandas numpy scikit-learn
```

2. Run the chosen experiment, for example:

```
python exp1\exp1.py
```
